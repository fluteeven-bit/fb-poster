# 社團貼文助手

給房仲用的 Facebook 多社團貼文管理工具。單一 HTML 檔案，不需要伺服器、不需要註冊。

## 功能

- **今日待辦** — 依冷卻天數自動判斷哪些社團今天可以貼
- **多社團批次** — 一次選多個社團，同分類的模板自動輪替，避免多社團貼出一模一樣的內容
- **排程** — 排定檔期，時間到在待辦區提醒（可開啟瀏覽器通知）
- **刪文管理** — 物件成交、保留期滿、版規限時、資訊要更正，四種情境自動排入待刪清單
- **成效追蹤** — 記錄各社團帶來幾組私訊，算出每則貼文平均成效
- **文案模板** — `{{變數}}` 自動代入物件與聯絡資料，內建 9 個房仲範本

## 使用

直接開網頁就能用。建議順序：設定 → 模板（載入範本）→ 社團 → 物件 → 產生貼文。

## 資料存在哪

**全部存在你自己瀏覽器的 localStorage，不會上傳到任何地方。** 這也表示：

- 換電腦、換瀏覽器不會同步
- 清除瀏覽資料會一併清掉

定期用「設定 → 匯出 JSON」備份。

## 為什麼不是全自動

Meta 在 2024 年 4 月停用 `publish_to_groups` 權限，官方 API 已經無法貼文或刪文到社團。宣稱全自動的第三方服務都是託管你的登入狀態去模擬操作，違反 Facebook 使用條款，帳號有被限制發文或停權的風險。

這個工具的定位是把準備工作做完 —— 文案生成、冷卻管理、模板輪替、刪文追蹤 —— 實際送出那幾秒維持手動。
